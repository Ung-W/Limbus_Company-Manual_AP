# Manual AP for Limbus Company

Made by EchoingEito with the help of Evoker

## Goal

You must beat your **Final Floor**

> Can define if you want your final floor to be between Floor 5 and 15 
 
## Randomization

### Character Related
- All Sinners
- All Sins (status effects)
- Ego slots
- Hyper specific Maost Key (to make mao faust a little harder to reach)

> To "Unlock" an ID, you must receive the Sinner and ALL the Sins necessary for their kit

### Gamemode related
- Grace starter buffs
- Ego gift space
- Shop abilities

### AP Gating
- Progressive Floors
  > Party Slots means all the "Sinner Slot +1" items + 1 (this one is implied since you can't go with 0 members in your party)
  - Floor 3+ requires 3 Sinners
  - Floor 5+ requires 3 Sinners and 3 Party Slots
  - Floor 8+ requires 7 Sinners and 3 Party Slots
  - Floor 10+ requires 7 Sinners and 7 Party Slots
  - Floor 13+ requires 12 Sinners and 7 Party Slots
  - Floor 15+ requires 12 Sinners and 12 Party Slots

## Locations
**You can select 2 progression type** :
- `Open` : Once unlocked, the whole floor is accessible.
- `Run` : Once unlocked, you have access to the first "Run" + a Boss, sending the "Floor x Boss y - Completion" will grant access to another "Run", if there is others set in YAML, and a "Reward" Check

You can configure the amount of "Runs" each floor will have.

1 Run = 5 Stages + 2 Boss checks

(if a Floor only has 1 Run, there is only 1 Boss Check)


- Floor 1 has 2 checks per Stage
- Your Final Floor will always have only 1 Run
